## 🏆 Projeto em destaque

<div align="center">

### 🍔 Romeu Lanches

**Uma aplicação real, desenvolvida do zero até a publicação.**

</div>

Um projeto independente que integra aplicativo mobile, painel administrativo e backend para gerenciamento de pedidos de uma lancheria.

| Camada | Tecnologias |
|:--|:--|
| 📱 Aplicativo e painel administrativo | Flutter · Dart |
| ⚙️ Backend | Java · Spring Boot |
| 🗄️ Banco de dados | PostgreSQL |
| ☁️ Infraestrutura | Supabase · Render |

O aplicativo foi publicado na Play Store, com o painel administrativo operacional e recebendo pedidos.

> 💡 Da interface ao backend e à infraestrutura: um projeto que conecta desenvolvimento, integração e entrega de um produto real.
